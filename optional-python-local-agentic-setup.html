Python Local Agentic Setup

Want to go beyond the browser? Here's how to get a professional-level coding environment that runs locally on your own laptop and is fully integrated with GitHub and Codex.

Step 1 — Install Python itself

  1. Go to python.org/downloads and download the installer for your operating system.

  2. Windows: run the installer and tick Add python.exe to PATH at the bottom of the first screen before clicking Install.

    Mac: run the installer with the default options — Python installs to the system PATH automatically.

  3. Open a fresh terminal (close and reopen VS Code, or any terminal window) and type python --version. It should print a version number, like Python 3.13.2.

The one that catches everyone On Windows, forgetting to tick Add python.exe to PATH is the single most common failure. If python --version says the command isn't recognized, re-run the installer, choose Modify, and turn that option on.

Step 2 — Connect it to VS Code

  1. In VS Code, open the Extensions view and install Python (by Microsoft). It pulls in Pylance automatically.

  2. Open your project folder, then open (or create) a .py file. Click the interpreter name in the bottom-right status bar and pick the Python version you just installed.

  3. Click the ▶ Run button in the top-right corner of the editor. A terminal panel opens at the bottom and shows your program's output — that's Python actually executing, not just Codex reading the file.

Once Python runs locally, the rest of the professional setup — Git, GitHub, and Codex all working together on your machine — is exactly what the Zero to Shared Code guide walks you through, from an empty laptop to a link you can share.
